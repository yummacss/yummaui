## What is Yumma UI?

Accessible React components built on [Base UI](https://base-ui.com/) & styled with Yumma CSS. You copy each one into your project & own every class.

## Getting started

Components are copied in, not installed, and `init` sets up Yumma CSS in a Vite or Next.js project.

<Stepper>
  <Step title="Create project">
    Start a React project with Vite, or with Next.js.

    <CodeGroup>

    ```bash title="Vite"
    pnpm create vite my-app --template react-ts
    ```

    ```bash title="Next.js"
    pnpm create next-app@latest my-app
    ```

    </CodeGroup>

  </Step>

  <Step title="Run init">
    `init` detects your project, asks where components live, then installs & configures Yumma CSS for you.

    ```bash
    pnpm dlx yummaui init
    ```

  </Step>

  <Step title="Add components">
    Name a component, or run `add` on its own to search the list. Anything a component needs from npm, such as `@base-ui/react`, is installed with it.

    ```bash
    pnpm dlx yummaui add button
    ```

    Each component lands as a single file you own.

  </Step>
</Stepper>

## Default configuration

`yumma.config.mjs` holds the states, curves & keyframes the components animate with, and the colors they paint with, light & dark.

<Note>
	A project that already has a `yumma.config.mjs` keeps it. `init` & `add` add
	what it lacks and leave what it defines, its own colors included.
</Note>

```js title="yumma.config.mjs"
import { defineConfig } from "yummacss";

export default defineConfig({
	source: ["./src/**/*.{js,jsx,ts,tsx,mdx}"],
	theme: {
		states: {
			closing: "[data-ending-style]",
			"from-left": "[data-activation-direction=left]",
			"from-right": "[data-activation-direction=right]",
			hovering: "[data-hovering]",
			opening: "[data-starting-style]",
			scrolling: "[data-scrolling]",
			swiping: "[data-swiping]",
		},
		easings: {
			"in-out-cubic": "cubic-bezier(0.65, 0, 0.35, 1)",
			"out-back": "cubic-bezier(0.34, 1.56, 0.64, 1)",
			"out-quart": "cubic-bezier(0.25, 1, 0.5, 1)",
		},
		keyframes: {
			pulse: "0%, 100% { opacity: .5; } 50% { opacity: 1; }",
			slide: "from { translate: -100% 0; } to { translate: 100% 0; }",
			spin: "to { rotate: 360deg; }",
		},
		colors: {
			raised: { light: "oklch(1 0 none)", dark: "oklch(0.305 0.008 264)" },
			well: { light: "oklch(0.955 0.003 265)", dark: "oklch(0.213 0.004 264)" },
			field: { light: "oklch(1 0 none)", dark: "oklch(0.213 0.004 264)" },
			fill: { light: "oklch(0.254 0.015 257)", dark: "oklch(0.933 0.005 248)" },
			"on-fill": { light: "oklch(1 0 none)", dark: "oklch(0.254 0.015 257)" },
			label: {
				light: "oklch(0.254 0.015 257)",
				dark: "oklch(0.944 0.003 286)",
			},
			hint: { light: "oklch(0.554 0.041 257)", dark: "oklch(0.693 0.01 273)" },
			rim: { light: "oklch(0.872 0.011 262)", dark: "oklch(0.386 0.006 258)" },
			shadow: {
				light: "oklch(0.748 0.023 259)",
				dark: "oklch(0.145 0.002 286)",
			},
			line: { light: "oklch(0.915 0.006 265)", dark: "oklch(0.309 0.004 265)" },
			check: {
				light: "oklch(0.546 0.215 263)",
				dark: "oklch(0.546 0.215 263)",
			},
			on: { light: "oklch(0.696 0.149 162)", dark: "oklch(0.696 0.149 162)" },
			knob: { light: "oklch(1 0 none)", dark: "oklch(0.933 0.005 248)" },
			focus: { light: "oklch(0.62 0.034 259)", dark: "oklch(0.685 0.027 256)" },
		},
	},
});
```
