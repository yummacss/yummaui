## What is Yumma UI?

Accessible React components built on [Base UI](https://base-ui.com/) & styled with Yumma CSS. You copy each one into your project & own every class.

## Getting started

Components are copied in, not installed, and `init` sets up Yumma CSS in a Vite or Next.js project.

<Stepper>
  <Step title="Create project">
    Start a React project with Vite, or with Next.js.

    <CodeGroup>

    ```bash title="Vite"
    pnpm create vite my-app --template react-ts
    ```

    ```bash title="Next.js"
    pnpm create next-app@latest my-app
    ```

    </CodeGroup>

  </Step>

  <Step title="Run init">
    `init` detects your project, asks where components live, then installs & configures Yumma CSS for you.

    ```bash
    pnpm dlx yummaui init
    ```

  </Step>

  <Step title="Add components">
    Name a component, or run `add` on its own to search the list. Anything a component needs from npm, such as `@base-ui/react`, is installed with it.

    ```bash
    pnpm dlx yummaui add button
    ```

    Each component lands as a single file you own.

  </Step>
</Stepper>

## Default configuration

`yummacss.config.mjs` holds the states, curves & keyframes the components animate with, and the colors they paint with, light & dark.

<Note>
	A project that already has a `yummacss.config.mjs` keeps it. `init` & `add`
	add what it lacks and leave what it defines, its own colors included.
</Note>

```js title="yummacss.config.mjs"

		states: {
			closing: "[data-ending-style]",
```
